# 🔧 Correcciones de Formato

Esta carpeta contiene los archivos con correcciones aplicadas a los NITs.

## Archivos

### CLIENTES_SOFTSEGUROS_CORREGIDO_YYYYMMDD_HHMMSS.xlsx
**Descripción:** Archivo completo de SOFTSEGUROS con NITs corregidos.

**Correcciones aplicadas:**
- 217 NITs corregidos con formato XXXXXXXXX-X
- Dígito verificador calculado según algoritmo DIAN
- Mantiene estructura original de 41 columnas
- Formato profesional en encabezados

**Uso:** Este archivo debe usarse como base para las siguientes etapas.

### REPORTE_CORRECCIONES_NITS_YYYYMMDD_HHMMSS.xlsx
**Descripción:** Detalle de todas las correcciones de NITs realizadas.

**Hojas:**
- **Resumen**: Estadísticas de correcciones
- **Correcciones**: Listado completo con NIT original → NIT corregido

**Ejemplos:**
- 900310074 → 900310074-1
- 900438817 → 900438817-6
