# tests - Pruebas Unitarias e Integración

Este directorio contiene los scripts y archivos de prueba para validar la correcta ejecución de los procesos de migración y transformación de datos.

## Uso
- Ejecuta los tests antes de cada migración para asegurar la calidad y consistencia de los datos procesados.
- Incluye pruebas unitarias para funciones clave y pruebas de integración para flujos completos.

## Recomendaciones
- Mantén los tests actualizados según los cambios en los scripts principales.
- Documenta los casos de prueba y resultados esperados.
- Usa datos de ejemplo en `data/samples/` para pruebas controladas.
