# Clientes Original - Migración SoftSeguros

Esta carpeta contiene los archivos originales de clientes exportados desde SoftSeguros y Celer, antes de cualquier transformación o validación.

## Contenido
- Archivos Excel con la base de datos original de clientes.
- Versiones históricas y actualizadas para trazabilidad.

## Uso
- Sirve como referencia y respaldo para comparar contra los datos transformados y validados en otras etapas del proceso.
- No modificar estos archivos directamente; cualquier cambio debe hacerse en las carpetas de procesamiento o migración.

## Recomendaciones
- Mantener los archivos originales intactos para auditoría y control de calidad.
- Usar los scripts de migración y validación para generar los archivos finales.
