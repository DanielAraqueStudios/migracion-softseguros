# docs - Documentación de Migración

Este directorio contiene especificaciones, diccionarios de datos, mapeos de campos y manuales de migración para el proyecto SoftSeguros.

## Archivos Clave
- Especificaciones de migración y flujos de trabajo.
- Diccionarios de datos y mapeos de campos entre sistemas.
- Manuales de usuario y guías de operación.

## Recomendaciones
- Mantén la documentación actualizada con cada cambio en los scripts y procesos.
- Documenta los mapeos y reglas de negocio para facilitar futuras migraciones y auditorías.
- Usa este directorio como referencia principal para onboarding de nuevos usuarios.
