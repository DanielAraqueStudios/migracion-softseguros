# Documentación

Documentación técnica y guías del sistema de migración.

## 📋 Descripción

Esta carpeta contiene toda la documentación del proyecto:
- Especificaciones técnicas
- Manuales de usuario
- Diagramas de flujo
- Guías de instalación y configuración

## 📁 Estructura

```
docs/
├── api/            # Documentación de APIs
├── guides/         # Guías de usuario
├── specs/          # Especificaciones técnicas
├── diagrams/       # Diagramas y flujos
└── examples/       # Ejemplos de uso
```

## 📊 Contenido

### Guías de Usuario
- `instalacion.md` - Guía de instalación
- `uso_basico.md` - Manual de uso básico
- `troubleshooting.md` - Solución de problemas

### Especificaciones Técnicas
- `formato_datos.md` - Especificación de formatos
- `algoritmos.md` - Algoritmos utilizados
- `reglas_validacion.md` - Reglas de validación

### Diagramas
- `flujo_etl.png` - Diagrama del proceso ETL
- `arquitectura.png` - Arquitectura del sistema

# Ver documentación
